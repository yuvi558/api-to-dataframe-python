# API to DataFrame using Python (Requests + Pandas)

This project demonstrates how to fetch real-world JSON data from a public API using Python and convert it into a clean Pandas DataFrame using `json_normalize()`.

## API Used
Stephen King Books API:
https://stephen-king-api.onrender.com/api/books

## Tools / Libraries
- Python
- Requests
- Pandas

## What This Project Does
- Sends a GET request to the API
- Converts the JSON response into Python data
- Converts nested JSON into a structured DataFrame
